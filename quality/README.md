Quality
-------
This directory contains source code useful to participate in FRIF TE QUality. The [Quality API] itself, [quality.h], is in the global [include] directory.

 * [libfrifte_quality]:
     - Implementation of `libfrifte_quality.so`---routines required by the [Quality API].
 * [nullimpl]:
     - Stub implementation of the [Quality API].
 * [validation]
     - Code to test and package [Quality API] implementations for submission to NIST for evaluation.

Communication
-------------
If you found a bug and can provide steps to reliably reproduce it, or if you
have a feature request, please [open an issue]. Other questions may be addressed
to the [NIST FRIF TE team].

The FRIF TE team sends updates about the FRIF TEs to their mailing list. Enter
your e-mail address on the [mailing list site], or send a blank e-mail to
FRIFTE+subscribe@list.nist.gov to be automatically subscribed.
