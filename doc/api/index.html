Friction Ridge Image and Features Technology Evaluations

Overview

This is the common application programming interface (API) that defines numerous functionality shared by all technology evaluations (TEs) under the National Institute of Standards and Technology (NIST)'s Friction Ridge Image and Features (FRIF) umbrella. Refer to the evaluation-specific FRIF API for more detailed information on wrapping algorithm code for testing under a NIST FRIF TE.
